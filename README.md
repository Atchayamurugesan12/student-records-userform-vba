# Student Management System (Excel VBA UserForm)

## Overview
A simple Student Management System developed using Microsoft Excel VBA UserForm. This project allows users to enter student details and store them automatically in an Excel worksheet.

## Tools Used

- Microsoft Excel
- VBA (Visual Basic for Applications)
- Excel UserForm

## Features

- User-friendly data entry form
- Automatic data storage in Excel
- Clear button to reset all fields

## How It Works

1. Open the Excel workbook.
2. Launch the Student Management UserForm.
3. Enter student details.
4. Click **Submit** to save the data.
5. Click **Clear** to reset the form.
